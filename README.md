# 本地虚拟商店购物车

计划管理本地商品目录、购物车和虚拟订单。面向本地单机使用，采用 Python 3 标准库与 SQLite。

## 当前范围

第一版仅包含两个固定演示商品的加入购物车、按编号移除、清空购物车与查看，以及基于 SQLite 的持久化购物车：

| 编号 | 名称 | 单价（分） |
| ---- | -------- | ---- |
| P001 | 虚拟笔记本 | 1200 |
| P002 | 虚拟马克杯 | 2500 |

所有操作离线完成，只依赖 Python 3 标准库，无需安装第三方包。

## 使用示例

```bash
# 加入购物车（同一商品重复加入会累计数量）
python shop.py add P001 2     # 输出：P001 数量 2
python shop.py add P002 1     # 输出：P002 数量 1

# 查看商品目录（按编号升序，只含编号、名称、单价）
python shop.py catalog
# P001 虚拟笔记本 1200
# P002 虚拟马克杯 2500

# 按关键词筛选：只输出编号或名称中包含该完整关键词的商品
python shop.py catalog 笔记
# P001 虚拟笔记本 1200

# 按单价升序浏览（数值比较，同价按编号升序；可带或不带关键词）
python shop.py price P002 900     # 输出：P002 单价 900
python shop.py catalog --sort price
# P002 虚拟马克杯 900
# P001 虚拟笔记本 1200
python shop.py catalog 笔记 --sort price
# P001 虚拟笔记本 1200

# 按单件预算浏览：只输出当前单价不超过上限（整数分）的商品，按编号升序
python shop.py budget 1200
# P001 虚拟笔记本 1200
# 预算与关键词同时筛选：单价不超过上限且编号或名称包含整个关键词
python shop.py budget 2500 --keyword 笔记
# P001 虚拟笔记本 1200
python shop.py --db budget.sqlite3 price P002 0  # 输出：P002 单价 0
python shop.py --db budget.sqlite3 budget 0
# P002 虚拟马克杯 0

# 查看购物车（按编号升序，金额单位为分）
python shop.py show
# P001 虚拟笔记本 1200 2 2400
# P002 虚拟马克杯 2500 1 2500
# 总数量 3
# 总金额 4900

# 预览应用固定满减后的结算金额（纯只读：不创建订单、不清空购物车）
python shop.py preview
# P001 虚拟笔记本 1200 2 2400
# P002 虚拟马克杯 2500 1 2500
# 总数量 3
# 总金额 4900
# 优惠金额 0
# 应付金额 4900

# 按商品编号移除整条购物车记录（一次性移除该商品的全部数量）
python shop.py remove P001     # 输出：P001 已移除
python shop.py show
# P002 虚拟马克杯 2500 1 2500
# 总数量 1
# 总金额 2500

# 一次性清空购物车中的全部条目（商品目录保留，购物车原本为空也同样成功）
python shop.py add P001 2      # 重新加入两件 P001
python shop.py clear           # 输出：购物车已清空
python shop.py show
# 总数量 0
# 总金额 0

# 按指定数量减少（数量是本次减少多少件，而非目标数量）
python shop.py add P001 2      # 重新加入两件 P001
python shop.py decrease P001 01  # 输出：P001 数量 1（前导零允许，保留剩余一件）
python shop.py decrease P001 1   # 输出：P001 数量 0（恰好减至零，记录被移除）
python shop.py decrease P001 1   # 标准错误：商品不在购物车（退出码 2）

# 直接设定已在购物车中商品的确定件数（不是累计，也不是减少量）
python shop.py add P001 2      # 重新加入两件 P001
python shop.py set P001 3      # 输出：P001 数量 3（保存后恰好为 3 件）
python shop.py set P001 3      # 输出：P001 数量 3（目标与当前相同也成功）
python shop.py set P001 000    # 输出：P001 数量 0（前导零允许，记录被移除）
python shop.py set P001 1      # 标准错误：商品不在购物车（退出码 2）
python shop.py set P001 2      # set 不负责首次加入：仍报商品不在购物车（退出码 2）

# 修改目录中已有商品的单价（单位为分，不影响名称、编号与购物车数量）
python shop.py add P001 2      # 重新加入两件 P001
python shop.py price P001 001500  # 输出：P001 单价 1500（前导零允许，按去前导零显示）
python shop.py show
# P001 虚拟笔记本 1500 2 3000
# P002 虚拟马克杯 2500 1 2500
# 总数量 3
# 总金额 5500
python shop.py price P001 0    # 输出：P001 单价 0（单价允许为零，商品仍留在目录和购物车）
python shop.py price P999 100  # 标准错误：未知商品（退出码 2）

# 使用指定的数据库文件（不同文件对应相互独立的购物车）
python shop.py --db other.sqlite3 add P001 1
python shop.py --db other.sqlite3 show
```

不指定 `--db` 时使用当前工作目录下的 `shop.sqlite3`。数据库首次使用时自动创建并写入两件固定商品，之后重复启动保留原有购物车内容。

## 规则说明

- `add`、`decrease` 的数量只接受由数字 0-9 组成且数值大于零的字符串（允许前导零，如 `007`）。
- `decrease` 的数量表示**本次减少多少件**，而非调整后的目标数量；成功时输出“商品编号 数量 剩余数量”。
  - 剩余数量大于零时继续保留该商品；恰好减至零时从购物车移除（仍输出数量 0），商品目录保持原样，之后仍可通过 `add` 重新加入。
  - 减少量超过现有数量时拒绝，不会自动清空或产生负数。
- `set 商品编号 目标数量` 把**已在购物车中**的商品直接改成确定件数：保存后的数量恰好等于目标，不累计，也不按减少量解释；目标与当前数量相同也成功。成功时输出“商品编号 数量 目标数量”。
  - 目标数量接受由数字 0-9 组成的非负整数字符串（允许前导零，`000` 按零处理）；与 `add`、`decrease` 不同，零是合法目标。
  - 目标大于零时覆盖为该件数；目标为零时从购物车移除该条记录（仍输出数量 0），商品目录保持原样。
  - `set` 不负责首次加入商品：编号在目录中但购物车没有该商品时报“商品不在购物车”，目标为零也一样；需先用 `add` 加入。
  - 目标数量超过 9223372036854775807 时报“数量超出范围”。
- `price 商品编号 单价` 为目录中已有商品保存新的整数分单价：只影响该商品的单价，不修改名称、编号与购物车数量；商品是否已加入购物车都可以修改，设成现有单价也成功。成功时输出“商品编号 单价 新值”，新值按去掉前导零后的十进制形式显示。
  - 单价接受由 ASCII 数字 0-9 组成的非空字符串（允许前导零，`000` 按零处理），单价允许为零；空字符串、空白、正负号、小数、全角数字或其他字符报“单价必须为非负整数”。
  - 单价超过 9223372036854775807 时报“单价超出范围”，超长纯数字参数也有确定结果，不出现异常堆栈。
  - 编号按原样精确匹配，不存在时报“未知商品”；参数齐全时错误判定顺序为单价格式、价格范围、商品编号。
  - 单价为零时商品继续留在目录和购物车中，对应小计为零；价格在重启后保留，不同数据库的价格互不影响。
- `clear` 一次性删除购物车中的全部条目，不接收商品编号或数量，也不要求确认；不删除数据库文件与商品目录，已保存的商品名称与价格保持不变，之后仍可通过 `add` 重新加入。购物车原本为空时同样成功，可重复执行。
- 行小计 = 单价 × 数量；总金额 = 各行小计之和；金额始终以整数分表示。
- `preview` 在 `show` 的商品行（编号、名称、单价、数量、小计，按编号升序）之后依次输出“总数量”“总金额”“优惠金额”“应付金额”四行汇总，标签与数值之间只有一个空格。
  - 固定满减：优惠前总金额达到或超过 5000 分时优惠 500 分，低于门槛时优惠为零；每次预览只减一次，达到多个门槛也不叠加；应付金额 = 总金额 − 优惠金额。
  - 纯只读：不创建订单、不清空购物车、不保存任何优惠状态；名称、单价、数量均以所选数据库当前内容为准，数据不变时重复预览结果一致，改价或调量后按新内容重新计算。
  - 空购物车不显示商品行，四行汇总均为零；零单价商品照常显示数量和零小计；行小计与合计即使超过 SQLite 整数保存上限也按 Python 整数精确显示。
  - `preview` 不接受业务参数，额外参数报“参数错误”（退出码 2）；数据库无法创建、打开或读取时报“数据库不可用”（退出码 1）。`show` 继续只展示优惠前的原始金额。
- 错误输出（标准错误）与退出码：
  - `数量必须为正整数`（退出码 2）：`add`、`decrease` 的数量为零、负数、小数、空字符串或其他文本。
  - `数量必须为非负整数`（退出码 2）：`set` 的目标数量为空字符串、带正负号、小数、空白、全角数字或混入其他字符。
  - `单价必须为非负整数`（退出码 2）：`price` 的单价为空字符串、空白、带正负号、小数、全角数字或混入其他字符。
  - `单价超出范围`（退出码 2）：单价超过 9223372036854775807；格式错误优先于范围错误，两者优先于编号错误。
  - `价格上限必须为非负整数`（退出码 2）：`budget` 的最高单价为空字符串、空白、带正负号、小数、全角数字或混入其他字符。
  - `价格上限超出范围`（退出码 2）：`budget` 的最高单价超过 9223372036854775807（含超长纯数字串）；调用结构校验先于格式校验，格式错误优先于范围错误，且都在打开数据库之前拒绝。
  - `未知商品`（退出码 2）：商品编号不存在；数量与编号同时无效时优先报告数量错误。
  - `商品不在购物车`（退出码 2）：编号在商品目录中但当前购物车没有该商品（含减至零后再次减少、重复移除、对未加入商品执行 `set`）。
  - `减少数量超过购物车数量`（退出码 2）：`decrease` 的减少量大于该商品当前数量。
  - `数量超出范围`（退出码 2）：数量或目标数量超过 9223372036854775807；对 `set` 而言格式错误优先于范围错误，两者优先于编号错误。
  - `参数错误`（退出码 2）：缺少参数、额外参数或未知子命令。
  - `数据库不可用`（退出码 1）：数据库无法创建、打开、读取目录或完成本次变更。
- `catalog` 只读商品目录：不增减购物车记录、不重置数量、不调整已有商品价格；已保存的商品名称与单价以数据库内容为准。可带一个可选关键词：带有关键词时只输出编号或名称中包含该完整关键词的商品（任一字段匹配即可，每件商品只出现一次，排序与格式不变）。匹配按区分大小写的原始文字进行，不转换大小写或全角字符，不按空格拆词，百分号、下划线等符号也不作为通配符；含非空白字符时首尾空格同样参与匹配。关键词为空或全为空白、或提供多个关键词时报参数错误；没有商品匹配时无任何输出并以退出码 0 成功。
  - 可选排序：在末尾追加两个独立参数 `--sort price`（只接受该大小写）时，本次展示按库中保存的整数分单价做数值升序，同价商品按编号升序，零单价排在正数前面；`catalog --sort price` 展示全部商品，`catalog 关键词 --sort price` 展示匹配商品。排序只影响本次展示，不保存排序偏好，也不修改商品资料或购物车；不带排序片段时仍按编号升序。为保留原调用语义，`catalog --sort` 中的 `--sort` 仍是单个关键词。不支持的排序值、重复排序片段及其他不符合新旧形式的组合都报参数错误（退出码 2），并在打开数据库之前拒绝。
- `budget 最高单价` 按单件预算只读浏览商品目录：只输出数据库中当前单价小于或等于上限的商品，按商品编号升序，每行沿用 catalog 的“编号 名称 单价”格式（字段间一个空格），不增加表头、汇总或预算提示；没有符合条件的商品时标准输出为空，仍以退出码 0 成功。比较针对单件商品的单价，与购物车数量和结算满减无关。
  - 可选关键词：在末尾追加两个独立参数 `--keyword 关键词`（只接受该大小写）时，商品还须编号或名称包含整个关键词才入选（任一字段匹配即可，每件只出现一次）。匹配规则与 catalog 关键词一致：按区分大小写的原始文字进行，不拆词、不转换大小写或全角字符，百分号、下划线等符号一律按普通字符处理；含非空白文字时首尾空格同样参与匹配。关键词位置的文字不解释为选项（以连字符开头也按字面关键词处理）。关键词条件只影响本次展示，不保存筛选条件，也不修改商品资料或购物车。
  - 名称与单价始终以所选数据库已保存的内容为准，不恢复内置演示价格；首次使用数据库仍按原规则初始化两件演示商品，对已有数据库不重置价格或购物车，重启后继续按保存的价格筛选，不同数据库互不影响。
  - 最高单价只接受由 ASCII 数字 0-9 组成的非空字符串（允许前导零和零），空字符串、空白、正负号、小数、全角数字或混入其他字符时报“价格上限必须为非负整数”（退出码 2）；数值超过 9223372036854775807（含超长纯数字串）时报“价格上限超出范围”（退出码 2）。只接受 `budget 最高单价` 与 `budget 最高单价 --keyword 关键词` 两种调用形式：缺少上限或关键词、关键词为空或全为空白、重复条件片段、排序片段及其他形式报“参数错误”（退出码 2），标记 `--keyword` 区分大小写。调用形式与关键词有效性先于上限格式校验，格式先于范围校验，这些错误均在打开数据库前拒绝，不创建数据库文件。
  - 纯只读：不修改商品资料和购物车；数据库无法创建、打开或读取商品时报“数据库不可用”（退出码 1）。
- 任何失败操作都不会改变已有购物车内容。
