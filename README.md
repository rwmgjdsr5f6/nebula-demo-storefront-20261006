# 本地虚拟商店购物车

本地单机的虚拟商店命令行程序，使用 Python 3 标准库与 SQLite，无需安装第三方包，可完全离线运行。

## 本次范围

第一版只包含固定的两个演示商品和持久化购物车：

| 编号 | 名称 | 单价 |
| --- | --- | ---: |
| P001 | 虚拟笔记本 | 1200 分 |
| P002 | 虚拟马克杯 | 2500 分 |

商品目录由程序固定提供，首次使用数据库时自动写入；商品资料不能通过命令行修改。

## 使用方法

### 加入购物车

```sh
python shop.py add 商品编号 数量
```

按商品编号找到商品后加入购物车；同一商品再次加入时数量累计。成功后在标准输出显示商品编号和累计数量，退出码为 0。

```sh
$ python shop.py add P001 2
P001 2
$ python shop.py add P002 1
P002 1
$ python shop.py add P001 1
P001 3
```

### 查看购物车

```sh
python shop.py show
```

按商品编号升序显示编号、名称、单价（分）、数量和行小计（分），末尾显示总数量与总金额：

```sh
$ python shop.py show
P001 虚拟笔记本 1200 3 3600
P002 虚拟马克杯 2500 1 2500
总数量 4
总金额 6100
```

行小计 = 单价 × 数量，总金额 = 所有行小计之和，金额始终以整数分表示。空购物车不显示商品行，总数量与总金额均为 0。

### 指定数据库文件

`add` 和 `show` 都可以在子命令前通过 `--db` 指定 SQLite 文件；不指定时使用当前工作目录下的 `shop.sqlite3`：

```sh
python shop.py --db data/shop.sqlite3 add P001 1
python shop.py --db data/shop.sqlite3 show
```

数据库首次使用时自动创建并保存两件商品；之后重复启动会保留原有购物车，不会重复插入商品。使用不同的数据库文件得到相互独立的购物车。

## 参数与错误说明

- 数量只接受由数字 0 至 9 组成且数值大于零的字符串，允许前导零（如 `007`）。
- 数量为零、负数、小数、空字符串或其他文本时，标准错误输出“数量必须为正整数”，退出码为 2。
- 商品编号未知时输出“未知商品”，退出码为 2；数量与编号同时无效时报告数量错误。
- 缺少参数、额外参数或未知子命令时输出“参数错误”，退出码为 2。
- 失败不会改变已有购物车。
- 数据库无法创建或打开时输出“数据库不可用”，退出码为 1。
